# 📝 TODO App

A simple TODO application built with **HTML, CSS and Vanilla JavaScript**.

The project was created to practice JavaScript fundamentals, DOM manipulation and browser storage without using any external libraries or frameworks.

## Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 💾 Automatic saving using Local Storage
- 🔍 Filter tasks (All / Active / Completed)
- 📅 Due dates
- 📂 Group tasks by due date
- 📊 Task statistics
- 🎨 Responsive interface with custom styling and animations

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)

## What I learned

During this project I practiced:

- DOM manipulation

- Working with arrays (`filter`, `sort`, `findIndex`, `forEach`)
- Objects and object manipulation
- Date handling in JavaScript
- Refactoring code into reusable functions
